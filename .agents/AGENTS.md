# Workspace Rules

## Slang & Override Rule Reporting Constraint
When reporting on or discussing classifier slang or rule-based overrides:
* **Do not print, quote, or list** the actual slang terms, keywords, or regex patterns in any user-facing responses, explanations, or updates.
* **Describe changes only in general terms** (e.g. "added N new terms across categories X, Y, Z" or "added vowel-elongation handling for M existing terms").
* This constraint applies to all model explanations, updates, chat responses, and pull request summaries, keeping the exact trigger set secure and hidden.
